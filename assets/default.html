Jalo - A simple Web Server

Jalo is a simple web server backend-framework written in C.

Simplicity and C doesn't sound good together atleast on web grounds, but sometimes, you just wanna write C and create a nice working website, specially during these times where LLMs can generate and spit out a complete working website in any javascript framework under 10 minutes.

The main reason Jalo is here is because, I wanna write the backend of my page in C (some of them). Frameworks like Flask and FastAPI are really good but Jalo is super good. It doesn't include overheads, consumes a small amount of memory, can run in any server (linux) on any low amount of RAM available. This might not be the easiest or the safest way to write a website but it is the most grounded way to write software. This exists as a direct competition to LLMs.
